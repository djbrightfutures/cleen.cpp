How it works

One model. Two speeds. You're always in control.

cleen wraps the llama.cpp-family runtime for local inference and OpenAI-compatible providers for cloud — behind a single model name and a single API.

01

Local

Free, private, runs on anything. Modern open models are Mixture-of-Experts — only a few experts fire per token, so they fit a small GPU or plain CPU and can even stream from your hard drive. Slower on weak hardware, but the model runs entirely on your machine.

02

Cloud

Fast, when you need speed. Burst to Luxucleen Cloud — the same models served at thousands of tokens a second. It's our own API, resold, and it's OpenAI-compatible. Pay only for the speed you use.

03

Smart router

Same model, same API, either way. cleen picks local vs cloud per request — or you force it with a flag (--local, --fast) or a header. The model identity stays identical, so nothing gets rewired.
