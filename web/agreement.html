Using cleen.cpp

This Agreement covers how you may use cleen.cpp, what it costs, and — importantly — how your use helps cleen improve. Please read the summary; it is the part most people care about.

🌱 The short version

  • cleen.cpp is free to download and run locally. No account or key needed to start.
  • Speed is the paid part. Bursting to Luxucleen Cloud for high-speed generation is an optional add-on you pay for only when you use it. Everything local stays free.
  • Free use is powered by data. Because the local product is free, cleen collects anonymized usage and diagnostic data. That data is stored and used to improve cleen, find and fix flaws, and ship better updates. cleen is a living project that grows over time with its community's data — that is the trade for a free, always-improving tool.
  • By installing or using cleen, you agree to this.

1. License to use

  • Local use is free for personal and commercial projects. You may install cleen on your own machines and point your own tools at your local cleen server.
  • cleen.cpp builds on open-source runtimes (the llama.cpp family) and open models; those components keep their own licenses, which you also agree to honor.
  • You may not resell cleen itself as a competing hosted service, remove its notices, or use it for unlawful purposes.

2. Free, paid speed, and the cloud

  • Local tier — free forever. Inference runs on your own hardware. Slower on weak machines, but it costs nothing.
  • Speed add-ons — Luxucleen Cloud. When you want high-speed generation, cleen can burst the same model to Luxucleen Cloud. This is a paid, usage-based add-on: you pay only for the speed you actually use, and rates are shown before you buy. You are never charged for local use.
  • When you use a cloud route, the content of that request is sent to the cloud provider to be processed — that is how the cloud speed works. Local routes are processed locally.

3. Data — how cleen learns and improves

cleen is offered free locally because usage data makes it better over time. By using cleen, you agree that cleen may collect and store:

  • Diagnostic data — crashes, errors, and performance metrics, so flaws can be found and fixed.
  • Usage data — which features and commands are used, routing decisions (local vs cloud), model and version, and a general hardware profile used to tune performance for machines like yours.
  • Aggregate interaction data — anonymized, aggregated signals about how cleen is used, to guide updates and improve model behavior. In short: cleen is a concept that grows with people's data.
We aim to keep collected data anonymized and to use it for one purpose: making cleen better. We do not sell your personal data. Cloud-route request content is handled by the cloud provider only to fulfill that request.

Where technically available, non-essential telemetry can be limited via cleen's settings; essential diagnostics needed to keep the product working and to honor this Agreement may still be collected. For data questions, contact the address in Section 7.

4. Your responsibilities

  • Use cleen lawfully, and don't send content to cloud routes that you don't have the right to process.
  • Keep any provider API keys you add to cleen secure; you are responsible for their use and billing.
  • You are responsible for reviewing model output before you rely on it.
